Berry Flames has entered the 2.0 state! Here's what's changed:

**Backend**
- Berry moved to a proper OOP structure! (I know, very exciting)
- Source code now up on github, and shared with the owner!

**Banking**
- Added the `/get_bits` command! No need to chat with Berry to get your current balance!
- Added the `/get_top_bit_holders` command! No need to ask Berry who the top holders are!
- Berry now rewards bits for chatting in all chat rooms!

**Chatting**
- Berry is less chatty! You have to say her name to chat with her!
- Added `/pie_attack`! Berry will now surprise your target with a pie after a random amount of messages!

**Private room creation**
- You no longer need to specify yourself as the participant when using `/create_room`. Berry now assumes you are meant to participate!
- Added the `/toggle_room_visibility` command! You can now flaunt your roleplay skills to all members of our community!
- Berry no longer announces your private room's creation (stay safe, lover pones!)

**Check-in**
- Use `/check-in` to gain a small rank! Each rank provides an extra bit for every message sent!
- Check-in levels reset after 48 hours. Make sure to `/check-in` daily!

It's not much for a 2.0 release, but reworking the backend took a bit of time.
Hulla will now get some rest before continuing the work ~///~
